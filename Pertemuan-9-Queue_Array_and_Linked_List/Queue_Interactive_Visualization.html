Queue Berbasis Array — Masalah "Antrian Semu"

Indeks front & rear bergerak tanpa melingkar (naif). Coba: enqueue beberapa, lalu dequeue, lalu enqueue lagi sampai slot kiri terbuang.

terisi kosong terbuang (wasted)
front = 0
rear = -1
ukuran = 0 / 5
status: KOSONG
Queue kosong. Mulai dengan Enqueue.
💡 Tips: enqueue 3×, dequeue 2×, lalu enqueue terus — perhatikan saat rear mentok di indeks 4, slot [0] & [1] yang kosong tidak bisa dipakai. Itulah false full.

Circular Queue — Solusi dengan Modulo

Rumus (index + 1) % KAPASITAS membuat indeks melingkar kembali ke 0. Slot yang sudah di-dequeue dipakai ulang — tidak ada pemborosan.

front = 0
rear = 4
ukuran = 0 / 5
status: KOSONG
Queue kosong. Enqueue untuk mulai. Perhatikan rear melingkar dari [4] → [0].
void enqueue(CircularQueue *q, int x) { if (isFull(q)) { printf("Penuh!\n"); return; } q->rear = (q->rear + 1) % KAPASITAS; // ← melingkar q->data[q->rear] = x; q->ukuran++; }

Queue Berbasis Linked List

Tanpa batas kapasitas. Enqueue → sambung di tail. Dequeue → lepas dari head. Keduanya O(1).

head → NULL
tail → NULL
jumlah node = 0
status: KOSONG
Queue kosong (head = tail = NULL).
⚠️ Jebakan tail dangling: saat node terakhir di-dequeue, head jadi NULL — tail harus di-reset ke NULL juga, atau enqueue berikutnya akan mengakses node yang sudah di-free.

Semua operasi menegakkan aturan FIFO — elemen pertama masuk selalu keluar pertama.
