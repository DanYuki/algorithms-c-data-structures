 Pointer Quick Reference
Syntax Meaning Example
int *p; Declare pointer to int p stores an address
&x Address-of operator — get address of x p = &x;
*p Dereference — read/write value at address p *p = 42;
int **pp; Pointer to pointer (double indirection) pp = &p;
*(p + n) Pointer arithmetic — access nth element same as p[n]
p[n] Array subscript (sugar for *(p+n)) arr[2] = *(arr+2)
NULL Null pointer — points to nothing (0) p = NULL;
sizeof(p) Size of pointer (8 bytes on 64-bit) 8 regardless of type
void *p Generic pointer — no type, needs cast (int*)malloc(...)
const int *p Pointer to const — can't modify value p itself can change
int * const p Const pointer — address fixed, value writable p can't be reassigned
Common pitfalls ⚠️
✗ Uninitialized pointer — int *p; *p = 5; // undefined behavior!
✗ NULL dereference — p = NULL; *p = 5; // segfault!
✗ Dangling pointer — free(p); *p = 5; // use after free!
✗ Type mismatch — double *p = &intVar; // wrong size!
✓ Always initialize — int *p = NULL; then assign before use
✓ Check NULL — if (p != NULL) { *p = 5; }
